# 🚁 Urban Feature Mapping from Aerial Images

A computer-vision based MVP that analyzes aerial/drone images and generates a map-style visualization of visible urban features such as vegetation, roads, and structural regions.

## 🎯 Problem Statement

Analyzing aerial imagery manually can take time. This project demonstrates how computer vision techniques can be used to automatically process an aerial image and highlight different urban features.

## ✨ Features

- Upload aerial/drone images
- Image preprocessing
- Vegetation detection
- Road/linear feature detection
- Structure detection
- Urban feature map visualization
- Basic analysis statistics
- Download processed result
